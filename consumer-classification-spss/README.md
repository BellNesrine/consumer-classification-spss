# Consumer Classification & Multivariate Statistical Analysis (SPSS)

## Project Overview

This project applies **Principal Component Analysis (PCA)** using IBM SPSS Statistics to explore consumption patterns across different socioprofessional categories.

The analysis aims to identify relationships between quantitative variables, reduce data dimensionality, and highlight similarities and differences between socioprofessional groups.

## Objectives

- Examine correlations between consumption-related variables.
- Apply Principal Component Analysis (PCA) to identify underlying patterns.
- Reduce the dimensionality of the dataset while preserving relevant information.
- Analyze the positioning of socioprofessional categories in the factorial space.
- Interpret statistical outputs and visualize relationships between variables and categories.

## Tools & Technologies

- **IBM SPSS Statistics** – Statistical analysis and PCA.
- **Microsoft Excel** – Dataset preparation and organization.
- **PDF Report** – Statistical results, visualizations, and interpretations.

## Methodology

The project follows a multivariate statistical analysis approach:

1. **Correlation Analysis:** Examination of relationships between the eight quantitative variables.
2. **Communalities:** Assessment of how well the variables are represented by the extracted components.
3. **Total Variance Explained:** Evaluation of the information retained by the principal components.
4. **Factor Score Analysis:** Examination of component coefficients and category positioning.
5. **Factorial Visualization:** Interpretation of variable and individual projection diagrams.

## Key Findings

- The first principal component explains **77.599%** of the total variance.
- The first two components together explain **88.595%** of the total variance.
- All eight variables have extraction communalities above 0.79.
- The analysis highlights distinct consumption profiles across socioprofessional categories.
- The factorial maps reveal relationships between consumption variables and differences between categories.
